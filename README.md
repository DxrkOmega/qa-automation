# Лабораторна робота № 1 — Розгортання середовища автоматизації тестування

Дисципліна «Автоматизація тестування», спеціальність F2, 4 курс.
Виконавець: Мигалка Олександр, група 3. Варіант: 5 (перевірка високосного року).

## Структура проєкту

```
src/temperature.ts        показовий приклад (Цельсій → Фаренгейт)
src/leapYear.ts           модуль за варіантом 5
tests/*.test.ts           тести Vitest
vitest.config.ts          конфігурація раннера і порогів покриття
tsconfig.json             налаштування TypeScript (strict)
eslint.config.mjs         лінтер
.prettierrc               форматувальник
```

## Встановлення і запуск

```
npm install
npm test            # одноразовий прогін
npm run test:watch  # режим спостереження
npm run coverage    # покриття (звіт: coverage/index.html)
npm run lint        # статичний аналіз
npm run format      # форматування
```

Потрібен Node.js 20+.
